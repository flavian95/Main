Chatbot 1 – AIML Rule-Based Chatbot

Requirements
Python 3.x
python-aiml library

Installation
pip install python-aiml

Running the chatbot
python bot.py

Memory
The chatbot stores user variables using AIML tags:
<set name="username"> and <get name="username">.

Technology
AIML (Artificial Intelligence Markup Language)
based on ALICE chatbot architecture.
